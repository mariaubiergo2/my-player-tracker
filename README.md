# Foot-Tracker (My Player Tracker)

Aplicación web colaborativa para el seguimiento del rendimiento deportivo de futbolistas.

## Desarrollo

### Cómo correr los tests

El proyecto incluye pruebas unitarias configuradas con **Vitest**. Para ejecutarlas, utiliza alguno de los siguientes comandos en tu terminal:

*   **Ejecución única (Modo CI):**
    ```bash
    npm run test
    ```

*   **Modo interactivo (Watch mode para desarrollo local):**
    ```bash
    npm run test:watch
    ```
